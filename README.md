
# Real-Time Character Counter

## Project Description
This project is a simple text area with a real-time character counter built using HTML, CSS, and JavaScript. It displays the number of characters typed and the number of characters remaining.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Text area for entering a message.
- Maximum character limit of 200 characters.
- Real-time character counter.
- Displays the number of characters typed.
- Shows a warning message when the character limit is reached.
- Prevents users from typing beyond the maximum character limit.
- Simple and user-friendly interface.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Type a message in the text area.
5. Observe the character counter updating in real time.
6. Continue typing until the 200-character limit is reached.

## Character Limit

- Maximum characters: 200
- Counter format: `150/200 characters`
- Remaining characters: Maximum limit minus characters typed.
- Warning message: Appears when the character limit is reached.
